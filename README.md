# GOBACKUP

## Description
这是使用Go语言和Fyne编写的一个图形化备份工具，支持以下功能：
- [x] 文件/文件夹备份 (20)
- [x] 文件/文件夹恢复 (20)
- [x] 文件类型支持 (10)
- [x] 打包解包 (10)
- [x] 压缩解压 (10)
- [x] 自定义备份 (5*5)
    - [x] 路径
    - [x] 文件类型
    - [x] 文件名称
    - [x] 文件大小
    - [x] 文件修改时间
- [x] 加密解密 (10)
- [x] 定时备份 (10)
- [ ] 实时备份 (10)
- [x] 网盘备份 (30)
    - [x] 拓展到网盘 (10)
    - [x] 用户管理 (5)
    - [x] 元数据管理 (5)
    - [x] 传输加密 (5)
    - [x] 增量备份 (5)
- Sum: 145分

## Usage

准备好 [GO](https://go.dev/) 环境，若要使用云盘，需要先在根目录下创建 `.env` 文件，内容如下：

```text
CLOUD = your_cloud_name
PORT = your_port
```

然后执行以下命令运行：
```shell
make deps // 安装依赖
make build // 构建
make run // 运行
```
